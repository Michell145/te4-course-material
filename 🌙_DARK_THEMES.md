## 🚀 Quick Theme Switching

### Method 1: Keyboard Shortcut
1. Press `Cmd + K, Cmd + T`
2. Use arrow keys to preview themes
3. Press `Enter` to apply

### Method 2: Command Palette  
1. Press `Cmd + Shift + P`
2. Type "Color Theme"
3. Select and preview themes

### Method 3: Settings JSON
Change the theme in `.vscode/settings.json`:
```json
"workbench.colorTheme": "Your-Favorite-Theme-Name"
```
